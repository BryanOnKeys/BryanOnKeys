## 03. Cómo abordo un proyecto

<table>
<tr>
<td width="33%" valign="top">

**01 · EXPERIENCIA**

Diseño de interfaces, navegación, formularios y comunicación clara con el usuario.

</td>
<td width="33%" valign="top">

**02 · APLICACIÓN**

Servicios, reglas de negocio, autorización, validación y APIs.

</td>
<td width="33%" valign="top">

**03 · PERSISTENCIA**

Modelos de datos, integridad, consultas y gestión de cambios.

</td>
</tr>
</table>

<details>
<summary><b>Ver mis principios de ingeniería</b></summary>

- **Claridad:** nombres comprensibles, responsabilidades definidas y documentación útil.
- **Seguridad:** comprobar permisos en el servidor y proteger información sensible.
- **Calidad:** considerar casos límite, errores y pruebas desde el diseño.
- **Mantenibilidad:** construir módulos fáciles de revisar, cambiar y evolucionar.
- **Colaboración:** comunicar decisiones técnicas y usar control de versiones.

</details>
